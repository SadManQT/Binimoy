- Base: `chunk-research` after LP-012
- Branch: `chunk-research`

- **LP-013 is partly done.** Drafting, approval, moderation, responses, appeal and withdrawal work. Evidence uploads and proof that a responder controls the shop's page do not exist.

## Implemented

- `@lp/db/community`: `saveDraft`, `submitReport`, `withdrawReport`, `appealReport`, `claimReport`, `decideReport`, `addFollowup`, `decideFollowup`, `moderationQueue`, `getReport`, `listMyReports`, `listPublished`.

## Contract and schema changes

- Schema file `0014_community.sql`, applied to Supabase: `community_report`, `community_report_event` (append-only), `community_followup`.
- States: `DRAFT → SUBMITTED → UNDER_REVIEW → PUBLISHED / NOT_PUBLISHED / NEEDS_INFORMATION`, plus `WITHDRAWN`. `UNDER_REVIEW` means a moderator has claimed it.
- No new error codes. `SECRET_SUSPECTED` is reused for identifiers in public text.

## Honesty notes

- `community.ts` was written after its test file, but the test was only seen failing as "module not found". All 8 passed on the first real run.
- The browser test passed on its first run and was never seen failing.
- The identifier check is a pattern match on long digit runs, emails and credential-like text. It does not catch names, addresses or photographed documents. The moderator's reading is the actual control.

## Not run

- Independent review.
- Any test with more than one moderator acting at the same moment beyond the claim race covered by a guarded update.

## Not built

- **Evidence attachments** (screenshots, receipts), their private originals and redacted copies, hashes (C9.2, D.9). A report is text only.
- **Proof of control of the response channel** (C9.4). Anyone signed in who is not the author can post a response; every response is shown with "not checked whether the writer speaks for this page".
- **A way for the reported shop to appeal a publication, an abuse report button, and a contact path** (D.10). Only the author can appeal, and only a refusal.
- **Duplicate and coordinated-submission detection** (C9.3) beyond the daily limit.
- **AI help structuring a report** (C9.1).
- **Notices** to the author or the subject when something is decided. The 72-hour window is stored and shown, but nobody is told.
- **Extension of the response window, late corrections after seven days on new evidence.**
- **Search invalidation after a correction** (D.10): there is no search index over community reports, only the exact-name list.
- Reports need sign-in to read. There is no anonymous public page.
