# ADR-008: Product name is Binimoy

- Status: ACCEPTED (founder decision)
- Date: 2026-10-12
- Affects: display name, README, package name, UI copy

## Decision

The product is named **Binimoy** (বিনিময়). "Lenden Prohori" was the working name in the v7 specification and is retired from user-facing text.

## Scope

- Changed: UI title and headings, README, root package name, local compose project name, AGENTS.md heading.
- Unchanged, per spec F3: the stable identifiers `LP-*`, `FE-*`, `CAT-*`, the `@lp/*` workspace package scope, and the text of `docs/MASTER_SPEC.md`.

## Not checked

Domain, trademark and market distinctiveness of the name have not been verified.
